# Audio-visual contract decision

The active AV document contains the semantic event, transport, audibility, reduced-motion, beat, and non-blocking rules that are currently valid. Earlier revision discussion, audition notes, implementation evidence, and deleted-surface references remain in `research/archive/document-reset-2026-08/original-audio-visual-contract.md`.

The AV contract is separate from ordinary UI architecture and from the acceptance registry. Mechanical event and manifest checks are offline. Human comfort and audibility are manual evidence only when AV behavior changes.
