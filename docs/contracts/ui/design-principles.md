# UI design principles

<!-- clause: UI-DESIGN-001 -->
The interface supports understanding and discovery during a solo Commander game. Repeated meaning operations use consistent affordances, visible state feedback, and reversible transactions.

<!-- clause: UI-DESIGN-002 -->
The interface does not score ordinary actions by speed, streak, or history length. Presentation follows successful semantic events. GameState never waits for animation, sound, or a browser policy decision.

<!-- clause: UI-DESIGN-003 -->
Every operation has a discoverable non-pointer alternative. A context menu or equivalent action surface is the fallback for drag, double-click, and compact-screen gestures.
