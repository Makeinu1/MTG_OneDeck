## Confirmed execution fractures closed

1. R1-A removed the partial automation-only command executor and routed automation through the canonical mutation owner. Unsupported runtime command shapes now fail closed.
2. R1-D preserves deterministic commands on mixed guided effects even when every target prompt was already stored at cast time.
3. R1-D no longer reports a stored target as applied when guided-command generation produced no executable command; the path remains visibly manual instead.
4. R1-D rechecks checked target selections at resolution and suppresses the whole targeted spell/ability when all targets are illegal, so deterministic mixed-guided commands are not executed through an invalidated target set.
